# Independent review and corrections

The final independent review found three Important issues and no Critical or Minor findings. A first reviewer could not run because of a provider usage limit; a second reviewer inspected the repository and reproduced the issues below. Corrections were verified with regression tests rather than a second review pass.

1. **Cancellation while an earlier submission was still uncertain.** A NOT_FOUND lookup schedules safe same-key replay, but cannot prove an earlier request will not commit. Cancellation previously saw PENDING and allowed the workflow to stop. The domain now treats that prior ambiguity as unresolved until a confirmed/skipped outcome exists. Regression tests observed HTTP 200 before the fix and now require HTTP 409 in both RETRY_WAIT and READY. A delayed original commit is still recorded, and cancellation becomes available after that ticket is confirmed.
2. **False real-model evaluation completion during provider outage.** The old gate checked adapter identity and 80 result rows, even if every call failed with 503. The report now counts actual inference responses independently of prediction quality and requires all 80 responses plus recorded revision metadata. An all-503 regression changed from a false completed gate to an incomplete gate. Invalid model predictions can still constitute a completed evaluation with zero accuracy; perfect predictions are not required.
3. **Redis-down scenario tested replay rather than new admission.** The fault case now creates its first workflow while the application's broker is unavailable, requires HTTP 202, verifies degraded broker readiness and durable MongoDB state, then demonstrates redispatch after broker availability returns. The corrected full matrix passed 200/200 expected outcomes in [run 40751719978](https://github.com/ishhaaab/maintenance-workflow-engine/actions/runs/40751719978). The earlier artifact is retained and labeled separately in the [fault report](../reports/faults.md).

The reviewer declined to infer remote service results from locally skipped tests, judge unrun live-model quality, or assess documentation still being written. Those are verified separately through linked CI artifacts and explicit completion gates. No minor findings were deferred.
